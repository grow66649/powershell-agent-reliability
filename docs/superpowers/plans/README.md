# Historical development plans

This directory preserves dated implementation, review-fix, evaluation, and publication plans from the development history of PowerShell Agent Reliability.

These files are useful for understanding how a particular change was scoped or reviewed at that time. They are **not** the current product contract, installation guide, release status, benchmark result, or contributor requirement.

For current information, start with:

- [`../../../README.md`](../../../README.md) for public scope and local setup;
- [`../../README.md`](../../README.md) for the documentation map;
- [`../../contracts/mcp-tool-contract-v0.2.md`](../../contracts/mcp-tool-contract-v0.2.md) for the current MCP surface;
- [`../../runbooks/codex-desktop-acceptance.md`](../../runbooks/codex-desktop-acceptance.md) for current Desktop runtime acceptance.

If a dated plan conflicts with newer source, tests, contracts, or runbooks, do not update the old plan to erase that history. Use the current material for present behavior and Git history for the development record.

Do not infer release maturity, adoption, performance, or successful experiment outcomes merely because a plan describes work that was intended to happen.
